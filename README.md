# Linked List Visualizer

An interactive, drag-and-drop web application built with **React** designed to make understanding Linked List data structures intuitive and visual. Whether you're a student learning CS fundamentals or just debugging a complex list, this tool brings pointers and nodes to life.

![Project Preview]([https://linked-list-visualizer-five.vercel.app/])

---

## 🚀 Features

* **Interactive Canvas:** Drag and drop nodes to rearrange your list visually.
* **Infinite Navigation:** Zoom in/out the canvas to handle lists of any size.
* **Smart Data Import:** Quickly populate your list by pasting raw data. Supports:
    * **CSV** (e.g., `1, 2, 3, 4`)
    * **Space-separated** (e.g., `10 20 30 40`)
* **Core Operations:**
    * **Append to End:** Dynamically add new data nodes to the tail.
    * **Insert at Front:** Quickly push new data to the head of the list.
* **Responsive UI:** A clean, modern interface designed for ease of use.

## 🛠 Tech Stack

* **Frontend:** React.js

## 📦 Getting Started

### Prerequisites

* [Node.js](https://nodejs.org/) (v14 or higher)
* npm or yarn

### Installation

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/MATRUNI/Linked-List_Visualizer](https://github.com/MATRUNI/Linked-List_Visualizer)
    cd Linked-List_Visualizer
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    # or
    yarn install
    ```

3.  **Start the development server:**
    ```bash
    npm run dev
    ```

4.  **Open in Browser:**
    Go to `http://localhost:5173` to view the visualizer.

---

## 💡 How to Use

1.  **Generate a List:** Use the input box to enter your numbers (e.g., `5, 10, 15` or `5 10 15`) and click **Generate**.
2.  **Drag & Organize:** Click and hold any node to reposition it on the screen.
3.  **Modify:** Use the "Append" and "Prepend" buttons to grow your linked list.
4.  **Explore:** Use your mouse scroll to zoom in and out.
